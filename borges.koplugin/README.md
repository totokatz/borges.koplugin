# Borges for KOReader

[Installation and downloads](https://github.com/totokatz/borges.koplugin#install-in-three-steps) · [Español](https://github.com/totokatz/borges.koplugin/blob/main/docs/README.es.md)

Copy the `borges.koplugin` folder into `koreader/plugins/`, restart KOReader and open **Tools → Borges → Account**.

For an existing installation, close KOReader, rename its plugin folder to `borges.koplugin`, and copy the new files over it. Keep your local configuration and only one installed copy.
